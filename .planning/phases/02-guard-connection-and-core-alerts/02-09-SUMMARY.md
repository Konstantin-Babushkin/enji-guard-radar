# 02-09 Summary: probe command

- `probe.py` (core): `Recording`, `RecordingGuardTools` (wraps any `GuardTools`, records answers and failure causes, rejects tools outside the read set), `RawReport`/`collect_reports` (pages joined as the parser sees them), `ProbeSummary`, `summarize`, `format_summary` (calls per tool, run and report statuses, severity words, layouts, unknown reasons, result shapes, tool arguments, dropped fields; counts and shape words only).
- `probe_sanitize.py` (core, pure): allowlist `sanitize_recordings` (stable placeholders by first appearance, consistent between arguments and responses, unknown fields dropped and counted), `rebuild_report` (structure kept, text replaced; fence-aware), and the three checks: `check_round_trip` (raw and rebuilt Markdown parse the same), `taint_strings`/`find_taint` (raw names, ids, titles, prose tokens must not survive; problems show 3 characters and a length), `scan_for_leaks` (email, non-`.example` URL, non-placeholder UUID/repo id, 40-hex SHA, secret patterns, long tokens outside `content_version`, source paths). `render_files` serialises the directory.
- `cli_probe.py` (shell) and `cli.py`: `probe --out DIR [--state-dir] [--config]`. Refuses a non-empty `--out` (exit 2) before connecting; walks `list_projects` then `fetch_project` for active projects through the recorder; a failed listing, a login failure or any refused check exits 1 with nothing written; otherwise writes into a temporary sibling directory and renames it onto `--out`. Prints the summary and the `git diff` review line; never runs git.
- Tests: `tests/test_probe.py` (57 rows: tracer through `cli.main` with a dirty fake Guard and a `run --dry-run --fixtures` replay, recorder, sanitizer, round trip, taint, leak tables, refusals, CLI edges), `tests/test_recorded_fixtures.py` (contract helper over `fixtures/guard-real*`, run on a probe-made directory in CI; `REQUIRE_RECORDING = False`, one skip naming plan 02-11). `cli_probe` added to `SHELL_MODULES`.
- Gate: `make verify` -> `1020 passed, 1 skipped in 15.10s`.
- Decision: a raw report whose fenced code block holds a `## ` or `### ` line is refused (the parser is not fence-aware, the rebuild is); the operator would see it in the probe output and decide in a gap-closure plan.
- Decision: the contract test lets a project be unknown, and a report fail to parse, only when the recording itself holds an error entry.
- Human checkpoint: the first real recording and the review of its `git diff` are plan 02-11 and are left to the operator. Nothing real was recorded here; no `fixtures/guard-real*` directory exists.
