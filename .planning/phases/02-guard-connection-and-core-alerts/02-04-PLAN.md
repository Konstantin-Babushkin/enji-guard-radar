## Settled questions and notes

- Re-arm is per run (D-06, RESOLVED in 02-RESEARCH.md Open Question 1), implemented in plan 02-01's reconcile; this plan feeds it by emitting every open series on every evaluated poll with count = latest_high. Age alone never sends (RESOLVED, Open Question 2). Age origin is D-02 as amended (RESOLVED, Open Question 4).
- A Phase 1 state file only ever came from fixture runs, because Phase 1 had no Guard adapter. On the first run over such a migrated state, a High series first seen on an already known project is therefore sent immediately like any other first sight on a known project. A real deployment starts without state, and its first run baselines everything (STATE-05).
- When two new runs of the same (repo, audit type) land between two polls, only the newest report is read (`newest_counting_runs_by_action_key`), so an intermediate clean run is not counted: conservative, slower to clear (research edge case).
- A repository missing from a complete repository listing (ProjectOk) is treated as removed: its series are dropped and their condition resolved. A run that is simply not on the read run pages leaves its series unchanged.
