## Failure behaviour

- Triager call: contract is never-raise; every failure is a TriageFailed reason -> rule-only text, one call log line, exit code and sends unchanged (D-11).
- Reply validation failure: whole or per item -> rule-only for those items.
- Cost file write: handled inside the store (one WARNING, run continues).
- State: saved before triage; triage cannot change it (asserted by the persistence row and in plan 04-14's matrix).
