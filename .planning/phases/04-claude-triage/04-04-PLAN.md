## Notes

- Interpretation (flagged for the operator): D-06 says "hex runs of 7 or more"; this plan drops such a run only when it holds at least one digit, so plain words made of a..f letters ("defaced", "acceded") are kept.
- Order of steps: secret check on raw -> control chars -> code spans -> tokens -> collapse -> cap -> letter count -> secret check on the result. Tokens are split on whitespace; trailing punctuation `.,;:!?)` is ignored when matching a token but kept if the token stays.
- The cap cuts at the last space at or before 80 characters (no ellipsis); a single 80+ character word is cut at 80.
