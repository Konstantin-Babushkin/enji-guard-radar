## Artifacts this phase produces

- `texts.py` new entries (en and ru): `marker.high` ("🔴"), `marker.other` ("🟡"), `alert.age` ("{days}d" / "{days} д"), `alert.high.line` ("{marker} <b>{name}</b> · {audit} High {previous}→{count} · {age}"), `alert.stale.line` ("{marker} <b>{name}</b> · no scan {age}"), `alert.never_ran.line` ("{marker} <b>{name}</b> · no scan yet"), `summary.short_header` ("Radar · {count} need attention"), `alert.where_repo` ("{audit} ({repo})"), `alert.triage_line` ("   {priority} · {cause}"). Russian wording is the executor's (Claude's Discretion), e.g. "нет проверок {age}", "проверок ещё не было", "Радар · требуют внимания: {count}".
- `messages.py` public helpers: `marker(kind: AlertKind, language) -> str`; `audit_short(action_key: str) -> str` (strip a leading `audit.`, then escape); `age_text(days: int, language) -> str`; `ambiguous_series(alerts) -> frozenset[tuple[str, str]]` ((project_id, action_key) pairs held by more than one repo in the set); `high_line(alert, *, language, show_repo: bool, arrow: bool) -> str` (arrow True: `High <prev or 0>→<count>`; False: `High <count>`).
- Old catalog keys that no module references any more after this plan (`alert.severity`, `alert.stale.title`, `alert.stale.body`, `alert.never_ran.*`, `alert.high.title`, `alert.high.rise`, `alert.high.seen_long`, `summary.header`, `summary.item.*`) are removed from both catalogs; keys still used by `reminders.py` and `digest.py` (`alert.high.count`, `alert.high.seen`, ...) stay until plans 04-06 and 04-09. `LONG_STANDING_PREFIX` is removed if nothing references it.
- Config keys: none.

## Notes

- `render_alert(alert, *, language, show_repo=False)` returns exactly one line. `render_messages` computes `ambiguous_series` over all alerts it renders and passes `show_repo` per alert, for single alerts and summary items alike, so two separate messages about two repos of one project stay distinguishable.
- `render_summary_item` returns the same line as `render_alert` (one shape for both). `summary_header(total, index, count, language)` keeps its signature and the " (k/n)" suffix.
- Age stays `alert.age_days` (Phase 2 D-02, from the radar's first sight). The digest footer that says so comes in plan 04-09; nothing is lost in alerts.
- Golden file: regenerate `tests/golden/dry_run_default.txt` the way `tests/test_language_e2e.py` documents, then read the diff: only the alert and summary lines (the "baseline, not sent" section and any immediate alerts) change; the digest section is unchanged in this plan.
