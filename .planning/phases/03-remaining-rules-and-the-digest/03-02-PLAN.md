## Notes

- A threshold of 0 never flags (a score is flagged only when strictly below it), which is how one project opts out while the section value is set; the example file says so. The per-project value `null` means "no override", as for the existing keys.
- `grace_hours` has no decided range; 1..168 keeps the window inside one week, so only one planned moment is ever open. Plan 03-07 makes `doctor` warn when it is shorter than the 3-hour timer.
- `tooling_gaps.window_days` range 7..365 and the per-project key name `tooling_window_days` are Claude's Discretion (03-CONTEXT.md: "config key names and validation messages, beyond the ranges named above").
